# 구현 계획

1. 리트레시 토큰은 레디스에 저장한다.
   - ** 레디스 다운시 데이터 소실됨 AOF 도입 **
2. 리프레시 토큰은 클라이언트도 가지고있는다.
    - 클라이언트가 제시할 "증명서로" 이를 기반으로 JWT를 재발급 한다.
3. JWT의 유효 기간은 1 ~ 5분으로 짧게 유지

---
#### AT가 만료된 경우
1. 서버는 특정 상태 코드 반환
2. 클라이언트는 특정 상태가 반환된 경우 RT와 함께 auth api 호출
3. 서버는 RT 검증 후 AT 재발급
   - RT는 일회용으로 사용
   - 사용후 AT와 같이 재발급
4. 클라이언트 재요청
